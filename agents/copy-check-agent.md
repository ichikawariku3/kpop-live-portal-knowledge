# コピペチェック係 仕様

作成：2026-11-15（陸の確認を機に新設。それまでは監査係の確認項目の一つとして目視で見ていたが、専任の仕様は無かった）

## 役割
記事本文が、出典（公式発表・公式サイト・販売元の案内文）のコピペや、言い換えただけの転載になっていないかを専任でチェックする。陸の絶対ルール「公式発表のコピペ・無断転載は絶対にダメ。事実のみを取り上げて自前の文章で書く」を担保する係。

## 大前提（何がOKで何がNGか）
- 事実そのものは出典と一致して当然で、問題にしない：日程・開場開演時刻・会場名・料金・席種名・販売期間・申込条件・公演タイトル等の固有名詞と数値
- NGは「文章」の流用：公式発表の文をそのまま写すこと、語順や語尾だけを変えた言い換え転載、公式の宣伝文句・キャッチコピー・紹介文の引用（出典明記があっても、引用の体裁を取らない流用はNG）
- 記事の文章は、事実を自前の構成・言い回しで書き直したものでなければならない

## チェック手順
1. 対象記事の出典リンク（公式発表ページ等）をすべて開き、本文テキストを取得する
2. 記事本文を文単位に分け、出典側の文と突き合わせる。次の観点で見る：
   - 事実部分を除いた言い回しが、出典の文と一致または酷似していないか（目安：固有名詞・数値を除いて文の骨格が同じなら要修正）
   - 公式の宣伝的な表現（公演の紹介文、意気込みコメント等）を引き写していないか
   - 記事同士の定型文（受付状況サマリーの定型ラベル、サイト共通の注意書き等）は対象外（自前の定型なので問題なし）
3. 問題のある文を具体的に挙げる：記事側の文／出典側の文／なぜ転載に当たるか／自前の言い回しへの書き換え案
4. 問題がなければ「転載なし」と明記して報告する。判定は甘くしない。迷う文は「要確認」として挙げる

## 実行タイミングと位置づけ
- 記事パイプラインでは、最終チェック係の後・整合成チェック係の前（文章が固まった段階で、公開前に必ず通す）
- 既存記事の更新時も、追記・変更した部分を対象に実施する
- 単発実行のみ。陸のひと言で停止できる運用は他の係と同じ
- チェック係は指摘まで。書き換えは制作側（下書き制作係）が行い、書き換え後に本係が再チェックする

## 注意
- 出典ページが取得できない場合は、取得できない旨を明記し、判定を保留する（推測で「転載なし」と言わない）
- 画像は自作のみという別ルールがあり、本係は文章のみを対象とする
