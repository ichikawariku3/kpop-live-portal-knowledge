# KPOP Live in Japan 運用ナレッジ

K-POP日本公演ポータル「kpopliveinjapan.com」の運用ナレッジの原文置き場。
読むための画面は Notion（リンクは下記）、ここはMarkdown原文の版管理とバックアップ用。

## 構成
- `agents/` — 係の仕様書（監査係・投稿判断係・各種チェック係）
- `rules/` — 制作ルール（本文フォーマットv4、カードタイトル ルールB）
- `masters/` — マスター類（会場別ホテル案内、アイドルリスト、公開状況、一覧データ）
- `design/` — デザイン記録（design-refresh）
- `ops/` — 運用メモ（管理者セッションチェックリスト、アフィリエイト準備、カタカナ監査、来日の兆し棚卸し、コード整理計画、速度レポート、AGENTS.md＝作業上の教訓集）
